Preguntas frecuentes

Todo lo que necesitas saber antes de empezar

Resolvemos las dudas más habituales sobre instalación, funcionamiento, datos y soporte.

¿TF3Gest ya se puede contratar?

No. TF3Gest se encuentra en preparación y todavía no acepta altas, contratos ni pagos. Las condiciones definitivas se publicarán antes del lanzamiento.

¿TF3Gest funciona con VeriFactu?

TF3Gest ya genera hash fiscal, encadenamiento, QR, auditoría y archivo legal. La transmisión automática a la AEAT está en desarrollo y está prevista para el lanzamiento.

¿Envía mensajes automáticamente por WhatsApp?

No. TF3Gest guarda el PDF, abre WhatsApp Web y prepara el mensaje. El usuario revisa, adjunta y confirma el envío, ya que WhatsApp no permite automatizar libremente ese paso.

¿Puedo importar mis datos actuales?

Sí. La migración inicial compatible está incluida tras revisar el formato, el volumen y la calidad de los datos. Pueden importarse clientes, vehículos, órdenes, facturas, históricos y varios catálogos desde CSV o una base compatible.

¿Necesito conexión permanente a Internet?

La aplicación principal trabaja de forma local en Windows. Algunas acciones externas, como abrir WhatsApp Web o servicios online, sí necesitan conexión.

¿Hace copias de seguridad?

Sí. Genera copias automáticas al cerrar la aplicación y después de emitir una factura, además de permitir comprobar y restaurar backups.

¿El precio de 29,90 € es definitivo?

Es el precio mensual previsto para el plan inicial de un usuario, con impuestos incluidos. Se confirmará antes de abrir la contratación.

¿Mis datos se guardan en la nube?

La base principal seguirá en el ordenador del taller. Las copias externas cifradas están previstas para el lanzamiento como protección adicional.
